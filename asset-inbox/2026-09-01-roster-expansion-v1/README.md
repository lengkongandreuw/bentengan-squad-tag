# Roster Expansion Asset Drop

Stored master assets for the 2026-09-01 roster expansion:

- Character-view portraits: Tui, Lui, Bebe, and Kodo.
- Six-row, seven-column gameplay sprite sources: Bebe and Kodo.

The original filenames are preserved inside this folder where practical. `hijau komo.png` is catalogued canonically as Kodo because the user requested the character name Kodo. Runtime files are derived as compressed WebP assets; these PNG files remain the master sources.
