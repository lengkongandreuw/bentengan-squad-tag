# UI Redesign References

Six user-supplied 1920×1080 PNG mockups received on 2026-09-01.

These files are retained as immutable visual references. The game does not load them at runtime. Runtime UI uses the derived, compressed assets in `public/ui-v2/` and the layout implemented in `app/prototype.tsx` and `app/globals.css`.

Reference flow: splash → team selection → character selection → arena selection → match.
