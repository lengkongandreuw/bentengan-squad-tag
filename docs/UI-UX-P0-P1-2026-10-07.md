# UI/UX P0–P1 — local implementation, 7 October 2026

Scope: the eight P0/P1 findings in `outputs/UI-UX-AUDIT-2026-10-06.md`.
No publish, commit or gameplay rebalance in this task. Existing user edits in
`config/map-studio.json` and its new WebP asset remain untouched.

## Implemented

- Real dynamic viewport on menu and gameplay; removed forced CSS rotation.
  Portrait remains usable and suggests landscape without pausing host simulation.
  Touch controls/primary character CTA fit inside viewport; upgrade is separate.
- Rules, HUD settings, upgrade and multiplayer panels stay in screen. Rules close
  remains visible when its content scrolls; lobby close uses a sticky header.
  Audio artwork scales to short landscape height so Save/Cancel stay reachable.
- Character confirmation resolves the selected or first playable arena using
  existing content gates. No additional unlocks/rewards/prerequisites are written.
- Tag eligibility is shared with simulation: `+ TAG`, `! AWAS`, `◇ KEBAL` are
  presentation-only hints, not promises of range/contact/line of sight. Cooldowns,
  flight, parkour and shields remain respected. Colors also follow this selector.
- Optional four-step in-match guidance observes sortie/tag/rescue progression;
  players can browse steps, hide and reopen it. No scripted match mutations.
  Client tag/rescue completion observes authoritative match stats.
- Rules now describe flight immunity through takeoff, flight and landing; upgraded
  durations are not presented as fixed base durations.
- Readable camera controls/score hierarchy, HUD text scale 100–130%, high contrast,
  and independent local HUD preferences. Artwork and image resolution unchanged.
- One primary Pick action; secondary Upgrade; duplicated unlock-button strip is
  replaced by the next character goal. Lock inspection through carousel remains.
- Centered lobby, Create/Join flows, profile name, folded technical note, copy/share
  invitation. Links carry arena selection; raw room codes retain manual arena
  selection. Content/build handshake still rejects mismatches.
