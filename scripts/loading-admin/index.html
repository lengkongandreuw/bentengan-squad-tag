BENTENG · LOADING STUDIO

Panel admin lokal · media loading, bukan durasi loading atau aturan gameplay.

Gambar umum dan GIF/WebP animasi tetap asli. Format gambar lain yang terbaca akan dikonversi ke PNG. Video harus dapat diputar browser (MP4/WebM/Ogg); codec yang tidak didukung perlu dikonversi terlebih dahulu.

Upload maksimal 60 MB. Disarankan video singkat, tanpa audio, dan media ringan agar loading tidak semakin berat. File lama tidak dihapus saat reset.

Simpan berlaku di lokal setelah reload game. Untuk situs publik, build/publish ke GitHub dilakukan terpisah. Tidak ada link panel ini di dalam game.
