# Bentengan Squad Tag

Prototype game web 2.5D **Bentengan 5v5** dengan aturan prioritas tangkap berdasarkan urutan keluar benteng, penjara dan rescue, stamina boost, serta item refill bertingkat.

## Mainkan

Versi publik: <https://lengkongandreuw.github.io/bentengan-squad-tag/>

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Build statis untuk GitHub Pages:

```bash
npm run build:pages
```

## Kontrol

- Gerak: `WASD` atau tombol panah
- Boost: tahan `Shift`
- Parkour: `Space`
- Jeda: `P`

## Status

Proyek ini adalah prototype gameplay single-player versus bot untuk memvalidasi mekanik dan game rules sebelum pengembangan multiplayer penuh.
